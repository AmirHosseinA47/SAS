0.6 SEED SELECTION RULE - WRITTEN DOWN BEFORE THE SCAN RUNS
    Seed sets 1-6 are spent (1-2 dispatch, 3-4 urgency, 5-6 movement). This
    round uses two NEW sets, numbered 7 and 8, by the rule of sets 1-6:
    seed = base + 4*s + w, s = A0 B1 C2 D3, w = N0 S1 E2 W3.
    (1) CANDIDATES: six-digit b with b = 1 (mod 20), 100001 <= b <= 999961, whose
        block b..b+15 lies outside 29000-32000 (the measurement round) and
        outside 572981-573036, 779981-780036, 135941-135996 and 287021-287076
        (sets 3-6 with their margins).
    (2) OCCURRENCE: a whole-token match (?<![0-9])N(?![0-9]) of any integer N in
        [b - 20, b + 35], in any file NAME, TEXT or BINARY content of the
        scanned trees (the movement round's scan list: the outputs/ of the main
        checkout - which now holds the merged movement-round records - and of
        the dispatch, urgency and zealous checkouts; docs/, tests/,
        src_extension/, the root *.py / *.md / *.txt; the memory directory;
        the quarantine directory and .git pruned by name before descending).
    (3) LISTING OCCURRENCE: an occurrence in a TEXT line that also names at
        least two of the eight bases the 2026-10-07 scan certified clean -
        135961, 287041, 474781, 575201, 662481, 674101, 741141, 819941. Such a
        line records a scan's output; it is not a use of a seed. A NAME or
        BINARY occurrence is never a listing occurrence. (Without this clause no
        base can be clean: the movement round's own scan summary, its Part 1d
        section 1d.4 and the project memory list all eight, so a literal-zero
        rule is now defeated by the scan records themselves.)
    (4) CLEAN(b) iff every occurrence for b is a listing occurrence (zero
        occurrences qualifies).
    (5) SET 7 = the smallest CLEAN base; SET 8 = the smallest CLEAN base at
        least 100 000 above set 7.
    (6) GIT HISTORY (all refs; pathspec excluding
        outputs/_firemech_rewound_20260914): no commit may add or remove a
        whole token of [b - 20, b + 35] on any line other than a listing line
        (3); otherwise that base is replaced by the next CLEAN base by (5). A
        positive control must find sets 5-6 in history.
    (7) The scan is a copy of outputs/_mvg_seedscan.py (outputs/_dq_seedscan.py)
