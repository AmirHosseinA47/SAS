F. THE SIDECAR  outputs/_cl_obs.py  (+ _cl_obs_stock.py, _cl_obs_crn.py launchers)
================================================================================
  Pattern: outputs/_fm2_probe_harness.py. install(repo) puts --repo first on sys.path,
  imports that checkout's agents / wildfire_model / common_fixed_variables /
  src_extension.planning.rescue_planner, and wraps attributes with PASS-THROUGH
  wrappers (call the original with the same arguments, return its result unchanged,
  draw no RNG, create no attribute on any model/agent object). Then it runs the inner
  harness via runpy in the same process:
      _cl_obs_stock.py -> outputs/_ffr_harness.py
      _cl_obs_crn.py   -> outputs/_fm2_probe_harness.py (which itself runs the harness)
  After the inner harness returns 0, write <out-without-.json>.clobs.json (atomic
  tmp + os.replace). NEVER modify the harness JSON or its .stdout.txt. If the inner
  harness exits non-zero, write nothing and propagate the code.
  A missing attribute (the 6160438 worktree has no ff_exit_leg_* / _exit_leg_*)
  is recorded as "ABSENT" and not wrapped.
  WRAPS (each wrapper increments counters and appends small events, capped at 5000):
    agents.ff_exit_leg_mode / _hold / _served : not wrapped; instead the VALUES are
        read once, at the first WildFireModel.step call (after apply_scenario_config),
        via the module functions -> "switches": {"mode":..,"hold":..,"served":..} or
        "ABSENT" per name.
    WildFireModel.__init__ : capture the model instance (a module-level list in the
        sidecar - NOT an attribute on the model).
    WildFireModel.step : record the current step (evaluation_timesteps_counter AFTER
        the call) for event stamping; first call reads the switches.
    Firefighter._mark_route_blocked : if self.exiting before the call -> counter
        "carrier_route_blocked" + event [step, unit_id, pos]. (Works at 6160438 too.)
    Firefighter._exit_leg_enclosed : counter "enclosed_calls" and, when it returns
        True, "enclosure_triggers" + event [step, unit, pos].
    Firefighter._exit_leg_hold : counter "holds" + event [step, unit, pos, victim_id].
    Firefighter._exit_leg_step : counters "path_steps" / "fallback_steps" from its
        return value + event [step, unit, from, to, outcome].
    WildFireModel._exit_leg_held_cell : counter "hold_starts" when it returns non-None.
    WildFireModel._exit_leg_custody : per call, the set size; counter "custody_victim_steps".
    rescue_planner._is_productively_served (the MODULE attribute; it is looked up as a
        global at call time) : counter "served_by_custody_only" when
        flags.get("in_custody") is True and the original logic WITHOUT that key would
        return False; also "served_by_custody_only_not_geo" when additionally
        flags["geo_reachable"] is False (that is a prevented streak increment). The
        wrapper must compute "original without the key" by calling the original on a
        shallow copy with "in_custody" removed - pure.
    WildFireModel.apply_physical_rescue_command : for action "unassign" with reason
        "firefighter_fire_casualty": event [step, ff, vid, sorted(metadata keys)].
  At the end: "transition_log_sha256" = sha256(json.dumps(model._movement_transition_log
  or [], sort_keys=True, default=repr)); "movement_reason_sha256" = sha256 of json of
  {unit_id: movement_reason} over firefighter_marker_agents, sort_keys, default=repr.
  Sidecar JSON keys: {"version":1, "harness": "stock"|"crn", "repo":..., "argv":[...],
  "switches":{...}, "counters":{...}, "events":{name:[...]}, "transition_log_sha256",
  "movement_reason_sha256", "absent":[names not found]}.
  NON-PERTURBATION is proven by G1: clC (through the sidecar) must equal uhD (recorded
  without it) on every key but tag and wall_s.

================================================================================
  CLI: --stage 1|2|3|all  --out <txt>  (default outputs/_cl_analysis_s<stage>.txt).
  Loads only files named by the queue files of the stages requested; for each run it
  REFUSES (SystemExit) unless: tag/wind/roles/seed/steps(360)/extra_params match its
  queue line; repo matches; fm2p state matches the instrument; the sidecar exists and
  its switches match; every extra_params key is an attribute of common_fixed_variables
  at the arm's repo (import-free check: parse the file text for "^KEY = "), except
  FM2P_* keys (the probe's).
  ROW CONVENTION (all metrics): an event stamped s happened during model step s;
  ff_steps[s-1] / ff_bind_steps[s-1] / victim_steps[s-1] are the state AFTER step s;
  the state at the START of step s is row s-2. Rows: ff_steps [ff, [x,y]|None, status,
  assigned, exiting, dead]; ff_bind_steps [ff, bound vid|"", available, rescue_completed,
  off_grid]; victim_steps [vid, [x,y]|None, status]; burn_intervals {"x,y": [[a, b|None],..]}
  = burning in the post-step observation of steps a..b-1.
  H1 IDENTITY (G1), all STOP on failure:
    (a) clB vs clC on C13: every top-level key except {tag, repo, wall_s} equal
        (params and extra_params EQUAL), incl. stdout_sha256/stdout_lines; sidecar
        transition_log_sha256 and movement_reason_sha256 equal. 13/13.
    (b) clC U30 vs recorded uhD (outputs/_ffr_uhD_*): every key except {tag, wall_s}.
        30/30.
    (c) prefix: clC C13 and clC U30 steps 1-240 vs recorded ugD (the _uh_analyze P2
        method: every per-step series [:240] equal - fire_digests, victim_steps,
        ff_steps, ff_bind_steps, uav_steps, uav_actions, partition_steps; every event
        list cut at step <= 240 equal).
    (d) CRN prefix: clKC U30 steps 1-240 vs recorded ugKD, same method, fm2p excluded,
        fm2p.config == {"FM2P_CRN": 1} asserted on both.
    (e) rb: clGC shard files vs _rblatch_camp2_ugGD{a,b,c,s}_D_{east|south}.json: every
        top-level key except tag equal; evals equal elementwise after dropping wall_s.
        4/4, 18/18.
    (f) clC sidecars: switches 0/False/0; holds, path_steps, fallback_steps, hold_starts,
        custody_victim_steps, served_by_custody_only all 0.
    (g) info only: clOC U30 vs recorded uhC (every key except tag, repo, wall_s, params,
        extra_params) - the mechanic-OFF control vs the recorded gated control.
  H2 LEGS: per exit_start (unit, victim) paired with that unit's completion of that
     victim before the victim's next exit_start. d = manhattan(pickup, recorded
     exit_target) (nearest boundary); d_c = manhattan(pickup, completions[].pos).
     M1a stalled iff n > d_c + 5; M1b iff n > d + 5 (n = completion step - exit step);
     M1c per exit_start: completed & M1a-stalled, OR broken (no completion; end cause
     from the unassign reason at the end step: replacement_after_blocked = drop,

     release; else "other"), OR horizon-cut with elapsed > d + 5.
