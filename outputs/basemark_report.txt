depotfireproof_part1.txt. The finding that makes attribution possible: the existing
firefighter_remove_fuel() draws no random number and a fuel-less cell KEEPS drawing
its number each tick, so a real arm's BURNING state must equal the control's exactly
until the first depot cell that would have ignited - and the corpus gives that step
per run. The finding that nearly broke it: the harness's fire digest hashes FUEL, so
the attribution test as I first wrote it would have failed in every run by
