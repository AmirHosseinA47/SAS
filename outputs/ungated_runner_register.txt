UNGATED RUNNER REGISTER - tooling whose meaning changes at the FF_FIREFIGHT_* default flip
Generated by outputs/_ug_register.py. Design: outputs/ungated_part1.txt 2.5.

THE FLIP: FF_FIREFIGHT_EXTINGUISH 0->1, FIREBREAK 0->1, ENGAGED_RETREAT_RANGE 3->1,
MISSION_GATE 1->0 (DRY_RUN stays 0). Idle firefighters now fight fire from step 1 in
every run that does not set these switches.

RULE (agents.Firefighter._firefight_prepare): a run is FF-SAFE iff it sets EXTINGUISH and
FIREBREAK explicitly and, when either is non-zero, ENGAGED_RETREAT_RANGE and MISSION_GATE
too. The minimal pin is --set FF_FIREFIGHT_EXTINGUISH=0 --set FF_FIREFIGHT_FIREBREAK=0.

WHAT BETRAYS A POST-FLIP RUN: harness JSON gains firefight_log / firefight_counters /
firefight_shadow / fire_cleared_unburned_final once any unit engages. Gate shards
(_rblatch_camp2_*), evaluate_scenarios text and custom probe JSON DO NOT. The pool
validators compare only a queue line's own --set list, so they call such runs VALID.

  f3RES            E=1 F=0 K=1 G=0
  f3OFF            E=0 F=0
  round 1 / f2 arms marked CHANGED in section A: set E and F to their recorded value (0 when the
  line did not set it), K to its recorded value (3 when unset) and G=0 (no gate existed then).
  Arms marked RESTORED need nothing beyond the recorded FF --set list.
  THE FF SWITCHES ALONE RESTORE THE CONFIGURATION, NOT THE WORLD. Every fm*/f2*/f3* arm was
  recorded before fireproof depots (6668368) and the searcher guard (629a321). To reproduce the
  recorded RUNS value for value at the current tree, ALSO pass --set BASE_STATION_FIREPROOF=0
  --set VICTIM_SEARCHER_HAZARD_GATE_BOUNDS_FIX=0 (proven: the ungated round's ugA arm, which
  does, is value-identical to round 1's fmEFS on 23/23; ugX, which does not, on 0/23).

HOW TO REUSE ANY OF THIS: set all four FF switches (or E=0 F=0) explicitly; new tags;
never edit a completed queue line in place; the E:/Projects/SAS_wt/ worktrees are gone.

EFFECTIVE CONFIGURATION NOTATION: 'E F K1 ungated' = extinguish, firebreak, engaged
range 1, no gate; '-' = that action impossible (extinguish needs K < 2); OFF = no action.
