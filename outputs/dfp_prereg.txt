B. THE 6.5 PARTITION - which seeds are pinned-comparable and which are not
------------------------------------------------------------------------------------------------
  A run is RE-ROLLED when its controls first depot ignition happens while a victim
  outcome can still move - strictly before terminal_step, or the run has no terminal step
  at all. From that step the two arms consume the shared RNG stream at different rates,
  so per-seed rescued / dead / never_detected signs are NOISE and are read POOLED only.
  A run whose depot ignition is AFTER terminal_step is pinned for VICTIM OUTCOMES by
  construction - but NOT for burnt_cells or vegetation, which keep moving after it.
  A run with NO depot ignition at all is pinned end to end and is a VACUOUS null.
